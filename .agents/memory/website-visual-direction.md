The user asked for the YAEL website to look more advanced, using Contratest's website as the reference.
**Why:** The user supplied https://www.contratest.com/shopping/paymentInit and said, “look how advanced this website looks!!!! make mine like this!!!!”
**How to apply:** Use it as visual inspiration, not permission to copy its brand, promotions, claims, or payment behavior. The supplied URL rendered its marketing homepage when inspected, not a visible checkout form.

The user wants “the apple arabic phont, like in iphones and macbooks” and rejected the previous colors as boring.
**Why:** Explicit correction of the app's appearance.
**How to apply:** Prefer the Apple system Arabic face on Apple devices, retain OS fallbacks elsewhere, and do not reintroduce Inter as an Arabic display override. Keep colors lively and legible in both themes; do not bundle proprietary Apple fonts.
