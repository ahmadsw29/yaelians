---
name: Model progress display
description: Completion checks and per-section progress visible before opening a model.
---
In the model library, show a green completion check on completed models and answered/total counts for each section on unfinished model cards, including while the cards are collapsed.

**Why:** The user asked to see what has been finished and how many questions remain without opening each model.

**How to apply:** Count answered questions, not correct answers. Keep completion distinct from an official passing grade. Use account-scoped saved attempts, refresh when returning to the library, and do not add counts from separate training and full-exam attempts or grant learning credit merely by displaying progress.
