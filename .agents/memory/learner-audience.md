name: Learner audience and tutor
description: Age range, study-guide character direction, and Arabic address for the YAEL app.
---

The app is for students aged 17–24. The primary guide should be an imaginary pet that looks hyped and cute, with supporting characters presenting questions beside the question text, not at the head of the progress bar.

**Why:** The user rejected Rami's appearance and asked for an unreal, hyped, cute pet and a playful learning experience like Duolingo. He is open to keeping Rami as a supporting character, but does not want a character on the progress line.

**How to apply:** Use original expressive creatures and question-presenter characters, not a cat or a copy of Duolingo's owl. Keep the experience relatable to late teens and university-age learners. Preserve customizable profile avatars as a separate feature.

The speaker button should make the Hebrew word sound like it is spoken by the presenting pet, rather than giving every character the same neutral voice.
**Why:** The user explicitly asked for words spoken with the pets' sounds when pressing the speaker.
**How to apply:** Give presenters distinct speaking styles without sacrificing clear Hebrew pronunciation or substituting animal noises. Current playback uses device Hebrew voices, so do not promise identical recorded voices across phones.

Address the learner in masculine Arabic, not feminine.

**Why:** The user explicitly requested the male version of learner-facing language.

**How to apply:** Use masculine forms in instructional, feedback, completion, and onboarding copy.

Keep answer feedback visual, without extra praise or encouragement sentences. A wrong-answer correction may still show the actual correct answer. The pet now belongs in its own animated celebration area in the empty space below the answers, not beside Next.

**Why:** The user asked to remove praise messages, then explicitly requested a separate “celebration park” because the pet beside Next made the button smaller.

**How to apply:** Keep Next full-width and outside the pet's layout. Use available empty space for movement, respect reduced motion, and never cover answers or navigation with decoration. Do not reintroduce praise sentences.

Use the same Arabic typeface in practice questions, answers, and navigation as on the home page.

**Why:** The user disliked the practice-screen Arabic and explicitly requested the home-page font.

**How to apply:** Keep Arabic typography shared instead of giving question bubbles and buttons separate font choices.

Vocabulary practice should show progress, the vocabulary category, the word and example, all four answers, and Next together without scrolling at normal text size. Keep Next near the bottom navigation, not far above it.

**Why:** The user explicitly corrected an oversized bottom gap and said he wants everything visible on one page without scrolling.

**How to apply:** Use a compact question layout and a persistent header; do not solve footer overlap by reserving excessive empty space. Preserve access to content when text is enlarged.

Reading comprehension must be a separate section, with its own home entry as the third practice card after vocabulary and restatement. Do not put a reading tab or mode switch inside vocabulary practice.
**Why:** The user requested reading in the third row, then explicitly rejected having it inside “مفردات” and asked to keep it separate.
**How to apply:** Preserve that home order and route-specific sessions. Shared rendering code is fine, but learners must not switch vocabulary and reading inside one round. Daily goal summaries are not practice cards.

Use Western digits `0123456789` throughout the app, not Arabic-Indic or Persian digits, while retaining Arabic text and RTL layout.
**Why:** The user explicitly requested “1234567890 numbers only not arabic ones!”
**How to apply:** Apply this to copy, goals, scores, timers, prices, dates, translation output, and design previews. Explicitly select Latin numbering for Arabic locale formatting; normalize digit input without changing saved numerical values.
